# One Inwise desktop application

`inwise-opensource` is the sole maintained Inwise desktop application and the source of its installer, recording flow, design, recovery, and any future desktop connectivity work.

`desktop-recording-sdk` is a retired prototype. Do not develop, build, launch, package, publish, or revive it. Do not split desktop features into a second app. Reopening that prototype requires an explicit human request.

Before diagnosing a desktop screen, verify the running executable and its repository. Normal use should launch the installed Inwise executable, not Electron from a retired SDK or a development checkout. Preserve user recordings and settings during app replacement.
