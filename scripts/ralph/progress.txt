## Codebase Patterns
- Tests are standalone Node.js scripts using `node:assert/strict`; export `run()` and guard with `if (require.main === module)`. Run with `ts-node --project tsconfig.main.json`.
- Typecheck via `node_modules/.bin/tsc -p tsconfig.main.json --noEmit` (no global tsc).
- In-memory NeDB for tests: each DB module exposes `__set<Name>DbForTests(db)` setters. Follow this pattern for new modules.
- Pipeline entry point for transcripts: `createMeetingFromTranscript({ title, content, date })` in `database.ts`, then `extractInsights(content)` + `saveInsights(meetingId, insights)`.
- Injectable deps pattern for testability: pass optional `deps` object with stub functions, default to real implementations.
