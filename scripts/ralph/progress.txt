## Codebase Patterns
- Electron main process uses `electron-store` for all local persistence (`config.ts`) — use `getConfig()` / `setConfig()` for reads/writes
- Build typecheck: `npm run build:main` (tsc -p tsconfig.main.json); no dedicated `typecheck` script
- Config interface in `config.ts` + defaults in the `Store<Config>` constructor must be updated together when adding new fields
- Slack fields already in config: `slackBotToken`, `slackReadChannels`, `slackWriteChannels`, `slackInactivityWindowMin`
- Logger: `log(level, tag, message)` from `./logger`
